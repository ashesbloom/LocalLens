Set it up

1
Install the agent
Grab the build for your platform.
brew install ashesbloom/locallens/locallens-agent
Open Releases ↗ All builds ↗
2
Connect it to Claude
The agent writes the MCP entry into Claude's config for you.
3
Restart Claude Desktop
LocalLens tools appear in the tool panel. Keep this app running — the agent talks to it.
4
Teach Claude your preferences
Optional, recommended. Paste this into Claude's custom instructions so it defaults to copy mode and scans before it sorts.

The agent finds this app by reading port.txt and authenticates with a secret in local_api_token.txt that only your user account can read. Every call is to 127.0.0.1. What reaches Claude is text — counts, folder names, and names you chose yourself. Never image data.
